# Ghostscript UI

A web interface for managing PDF and PostScript conversions using Ghostscript. The project aims to simplify batch document processing with a containerized backend and lightweight front end.

**Status:** Historical project sketch and internal automation candidate. This
directory contains documentation and a setup placeholder, not a verified
released implementation. The architecture describes the proposed design.

## Scripts

- `scripts/setup.sh` – initializes the ghostscript_ui environment.
