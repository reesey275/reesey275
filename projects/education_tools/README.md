# Education Tools

Collection of small learning applications, such as algebra problem generators and interactive study guides. Designed to aid self-paced education and demonstrate lightweight web deployment.

**Status:** Historical development concepts. This directory contains
documentation and a setup placeholder, not verified released applications.
The architecture describes a proposed design; current implementation and
deployment status are unverified.

## Scripts

- `scripts/setup.sh` – initializes the education_tools environment.
